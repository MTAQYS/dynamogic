## Launch playbooks

### Reddit
- Read sub rules (`r/SaaS`, `r/Entrepreneur`, `r/ClaudeAI`, `r/nextjs`, `r/SideProject`).  
- Lead with problem + demo GIF; disclose founder; no fake accounts.  
- Avoid spammy multi-sub blast same hour.  
- Offer free founding Q&A; link demo first, pricing second.

### Hacker News (Show HN)
- Title pattern: `Show HN: Dynamogic – brand kits for AI-generated PDFs (demo + MCP)`  
- First comment: stack, what’s hard (Chromium render), what’s not claimed (not Canva).  
- Be online for 4–6h; answer technical questions; link docs.  
- Do not ask for upvotes.

### Product Hunt
- Gallery: monochrome UI + one colorful PDF preview.  
- Tagline ≤ 60 chars: “Brand layer for AI output — PDFs via web & MCP”  
- First comment: story, pricing, founding 50.  
- Hunt allies: real users/friends; no bots.  
- Prepare thumbnail per `LOGO-BRIEF.md`.
