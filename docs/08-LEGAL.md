# 08 — Legal (checklist + outlines)

**Not lawyer text.** Founder should have Privacy Policy & Terms reviewed for the operating jurisdiction. This doc lists **what must be covered** and suggested section outlines.

---

## Cookie / analytics note

- Prefer **Plausible** or **Umami** (cookieless or minimal cookies).  
- If using only cookieless analytics: still disclose “privacy-friendly analytics” in Privacy Policy.  
- If any advertising pixels (Meta/X): disclose, obtain consent where required (EU/UK), document in cookie banner / preference center.  
- Lemon Squeezy & Brevo set their own cookies on their domains — disclose third-party processors.  
- Do **not** enable non-essential pixels before consent mechanism if targeting EU/UK users.

---

## Privacy Policy — must cover

- [ ] Who the controller is (MTAQYS / Mohamed-Taqy Salmi legal entity name + contact email)  
- [ ] What data you collect (account email, brand kits, content submitted for render, usage counters, IP/rate-limit, payment metadata via Lemon Squeezy)  
- [ ] Purpose of processing (provide service, security, billing, support, analytics)  
- [ ] Legal bases if GDPR applies (contract, legitimate interest, consent)  
- [ ] Processors / sub-processors: Supabase, Vercel, VPS host, Brevo, Lemon Squeezy, analytics, uptime  
- [ ] International transfers (where data is hosted)  
- [ ] Retention (account data, PDFs, share links, logs)  
- [ ] User rights (access, deletion, export) + how to request  
- [ ] Children’s data (not directed to children under 16/13 as applicable)  
- [ ] Marketing email vs transactional (Brevo) — opt-out for marketing  
- [ ] Security measures (high level — hashing API keys, TLS, etc.)  
- [ ] Changes to policy + date  

### Outline sections
1. Introduction  
2. Data we collect  
3. How we use data  
4. Legal bases (if needed)  
5. Sharing & processors  
6. Cookies & analytics  
7. Retention  
8. Security  
9. Your rights  
10. International transfers  
11. Contact  
12. Updates

## Terms of Service — must cover

- [ ] Description of service (branded PDF generation; demos, API, MCP)  
- [ ] Accounts & eligibility  
- [ ] Acceptable use (no malware, illegal content, abuse of render workers, scraping quotas)  
- [ ] Content ownership: user keeps content; license to process for rendering  
- [ ] Free tier & paid plans; founding seat cap (50); fair-use caps  
- [ ] Billing via Lemon Squeezy; renewals; cancellations  
- [ ] Refunds policy (explicit)  
- [ ] API / MCP fair use & key responsibility  
- [ ] Disclaimer of warranties (service “as available”)  
- [ ] Limitation of liability  
- [ ] Indemnity (user content)  
- [ ] Termination  
- [ ] Governing law / dispute venue  
- [ ] Contact
